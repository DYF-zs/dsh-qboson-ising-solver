常见问题解答
======================

license文件生成异常
-------------------
- 生成license需要连接国内网络, 建议本地生成license，服务器下载license时候请检查服务器网络配置

Python版本错误
-------------------
- 目前SDK只支持Python3.10版本，不区分小版本

Mac架构错误
-------------------
- mac有intel和m芯片系列，请尝试SDK的intel和m版本，但是不一定完全匹配，有可能m芯片的mac book需要intel版本的SDK

授权码到期
-------------------
- 请到专用量子云平台重新生成申请

SDK导入错误（ModuleNotFoundError）
--------------------------------------
- 请检查当前项目路径是否已经添加到Path中

安装最新版本SDK
--------------------------------------
- 按照教程执行安装命令即可，会覆盖旧版本
